## Streaming Regenerate State Machine

States: `loading` (initial fetch) → `idle with briefing` / `empty` (no row) → `streaming` (POST in flight) → `idle with briefing` (re-fetched after event: done)

SSE consumption pattern:
1. `fetch('/api/daily-prep/briefing', { method: 'POST' })` — not EventSource (POST body support required)
2. `response.body.getReader()` + `TextDecoder` line-buffer accumulation
3. `data: {"text":"..."}` lines → accumulate in `streamingText`, render progressively via ReactMarkdown
4. `event: done` line → re-fetch GET to get canonical persisted row (id + generated_at from DB)
5. Fall back to `{ id: 0, ...accumulated }` if re-fetch fails (stream integrity preserved)
