## System Prompt

The SYSTEM_PROMPT const instructs Claude to produce exactly three markdown sections:

```
## Today's Meetings
## Today's Action Items
## This Week's Critical Items
```

Rules: max 5 per section, tight executive prose, no tables/emojis/nested bullets, action items use `description` field from ActionCandidate (not title).

The prompt is embedded in the route file (not a skill file) — it is route-specific synthesis logic, not a reusable AI skill.

## Empty-Data Short-Circuit

Triggers when: `meetingsWithBriefs.length + meetingsWithoutBriefs.length + actionsList.length + critical.risks.length + critical.milestones.length + critical.decisions.length + critical.wbsItems.length === 0`

Behavior:
1. Builds static 3-section markdown ("Nothing scheduled / No open actions / Nothing urgent")
2. Calls `persistBriefing()` — errors are caught + logged (non-fatal)
3. Emits `data: { text }` + `event: done\ndata: {}` via SSE
4. No Anthropic API call

## Persist Failure Handling

`persistBriefing()` is called inside a try/catch in both the Claude streaming path and the empty-data path. Any DB error is:
- Logged via `console.error('[briefing] ...')`
- Silently swallowed — `event: done` is emitted regardless
- Stream integrity is preserved even if DB is unavailable
